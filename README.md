# Heyyy Hajera — Happy New Year

This is a small React + Vite project created as a surprise page. It shows a cute animated home page with stickers and interactive Yes / No buttons.

How to run locally (Windows PowerShell):

1. Install dependencies:

```powershell
npm install
```

2. Start dev server:

```powershell
npm run dev
```

Open the URL shown by Vite (usually http://localhost:5173).

What's included:
- `src/components/Home.jsx` — main UI with animations and buttons
- `src/styles.css` — styling and keyframe animations
